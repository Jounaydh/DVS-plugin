DVS Plugin 0.4.0 for PyCharm on macOS

1. Open PyCharm.
2. Choose PyCharm > Settings > Plugins.
3. Open the gear menu and choose Install Plugin from Disk.
4. Select dvs-visualizer-pycharm-macos-0.4.0.zip from this disk image.
5. Restart PyCharm and select DVS from the left tool-window bar.

Do not extract the plugin ZIP before installing it.

The plugin analyzes supported project files locally and requires a normal
PyCharm installation with JCEF enabled.
