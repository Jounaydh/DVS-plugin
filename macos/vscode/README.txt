DVS Plugin 0.4.0 for Visual Studio Code on macOS

1. Open Install DVS Plugin.app.
2. If macOS blocks the unsigned development app, Control-click it, choose Open,
   and confirm.
3. Restart Visual Studio Code if it was already running.
4. Open a project and select DVS from the left Activity Bar.

Manual fallback:
Open Visual Studio Code, run "Extensions: Install from VSIX...", and select the
dvs-visualizer-0.4.0.vsix file bundled inside the installer app's Resources
folder.
