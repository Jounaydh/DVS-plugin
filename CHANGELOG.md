# Changelog

## 0.4.0

- Made the DVS Activity Bar container and Maps & Controls view explicitly
  visible in the left sidebar.
- Added a native Windows installer for the VS Code extension.
- Added a separate JetBrains Platform plugin with a left-side DVS tool window
  for PyCharm.

## 0.3.1

- Replaced the simplified webview with the desktop DVS visualizer UI.
- Reused the desktop 2D map, logic map, toolbar, workflow nodes, layout engines,
  filters, evidence inspector, zoom/pan behavior, and complete visualizer CSS.
- Reused the desktop multi-language static-analysis pipeline for symbols,
  imports, logical relationships, SQL schemas, and database access.
- Added all four workflow directions, free positioning, custom-position reset,
  Guided/Advanced modes, fullscreen, and source-evidence navigation.
- Opened the visualizer as a full editor tab so its desktop layout has room.

## 0.2.0

- Added dedicated 2D workspace and logic relationship maps.
- Added horizontal and vertical graph layouts.
- Added zoom, fit, search, filtering, and relationship legend controls.
- Added Activity Bar quick access, status-bar launch, and keyboard shortcuts.
- Reorganized analysis, provider, and webview source modules.

## 0.1.0

- Added local workspace dependency visualization.
- Added PyTorch `nn.Module`, layer, and `forward()` flow detection.
- Added interactive filtering, source navigation, and graph refresh.
